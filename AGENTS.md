# What the website is for

To spread awareness about autism and meltdowns, which is something people with autism spectrum disorder face. It is also to provide resources for caregivers and the people they care for who have ASD to improve their train journey experience.

# Website rules
Static HTML/CSS, no build step. Follow the design given in Figma. The website will only be in Mobile format.

## Pages

Pages have their static images in the Figma file shared. In total, there will be three pages.

## Design rules

- Background: #023924, headers: #F29BC6, text: #000000, accent:#FFB8FA
- Header Font: Monomaniac One, Body Font: DM sans
- Left-aligned, generous white space
- No gradients, no drop shadows, no centred body text

## Structure

- index.html - the whole page
- assets/ - images

## Features and interactions

Buttons should change colour when pressed, and there should be smooth but gentle animation when the user scrolls the website up or down.
